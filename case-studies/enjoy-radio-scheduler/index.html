The Challenge

Four Critical Automation Failures

ENJOY Radio was suffering from compounding scheduler issues that together made 24/7 professional broadcasting impossible.

Multiple Jingles Playing Consecutively

3+ jingles firing back-to-back before hourly TOP announcements. Long periods without any jingles followed by bursts. Station branding frequency completely unpredictable, destroying professional radio flow.

Hourly TOP Looping Infinitely

Critical failure: TOP Horaire hourly announcement triggering correctly then replaying in an endless loop — halting all music playback and breaking the listener experience for extended periods.

Scheduler Queue Corruption

Playlist queue corrupting mid-broadcast — incorrect track replacement, overlay conflicts, unexpected queue resume behavior. Unpredictable output making reliable scheduling impossible.

Playlist Architecture Limitations

Heavy reliance on random rotation logic causing unpredictable transitions, uneven jingle distribution, and inability to control exact hourly programming — no deterministic scheduling possible.

The Solution

Deep Scheduler Engineering & Rebuild

We performed a systematic investigation of every layer of the RadioBOSS Cloud scheduler — testing 5+ playback configurations to find the optimal stable setup.

1

Full Scheduler XML Analysis

Deep investigation of scheduler XML structure, event configurations, queue behavior, overlay system, playlist priorities, and hourly event execution. Reviewed backup XMLs, event logs, and playback history.

2

Jingle Rotation Rebuild

Reworked jingle handling to achieve consistent "2 songs → 1 jingle" flow. Reduced conflicting jingle blocks, simplified rotation logic, tested multiple methods to eliminate consecutive jingle bursts.

3

TOP Horaire Loop Elimination

Tested 5+ RadioBOSS playback modes — overlay, queue replacement, pause playlist, replace scheduled tracks, enqueue logic — to find the stable configuration that prevents infinite TOP looping permanently.

4

Optimal Overlay Configuration

Implemented the safest stable configuration: Overlay Playback ON + Pause Playlist ON. Result: current song pauses → TOP plays → same song resumes. Stable, loop-free, zero queue corruption.

5

Advanced Hourly Playlist Architecture

Designed a scalable day-based hourly playlist system — Lundi 01, Mardi 14, Vendredi 20, Dimanche 24 — enabling deterministic hour-specific programming and future scaling without conflicts.

6

Custom XML Scheduler Generation

Delivered fully structured, color-coded, grouped scheduler XML with UI-enhanced readable layout — weekdays color-coded, events grouped, admin workflow significantly simplified.
