The Client

One Client, Two Stations, Two Different Missions

Fritzner Moussignac is a Haitian-American radio entrepreneur with a passion for Haitian culture and community. He came to RadioTech Studio with two distinct radio projects that needed to be built simultaneously — each with its own identity, audience, and technical requirements.

🇺🇸 Nostalgie FM — New Jersey, USA

Nostalgie FM

An online Haitian nostalgia radio station broadcasting from Hackettstown, New Jersey — serving the global Haitian diaspora with non-stop classic Haitian music (Kompas Dirèk, Konpa, Mini-Djaz) since 2002. The station preserves and shares Haiti's golden musical era with listeners worldwide.

RadioBOSS on Windows Server Song Request System (2 per 30 min) Global Haitian Diaspora Audience

🇭🇹 Fonds-des-Nègres FM — Haiti

Fonds-des-Nègres FM

A French/Haitian Creole community radio station based in Fonds-des-Nègres, Grand Sud, Haiti — serving as the primary local voice for news, culture, sports, and community programming in the region. Their tagline: "Quand Fonds-des-Nègres parle, tout le Grand Sud écoute."

RadioBOSS Cloud Streaming Community News & Journalism Live Shows: Sports Info, Soirée Détente

The Challenge

Two Stations — Four Core Problems to Solve

No Professional Websites

Both stations had no proper online presence — no live player, no show schedules, no galleries, no news. Listeners had no professional digital home to visit.

RadioBOSS Not Fully Configured

Nostalgie FM had RadioBOSS on Windows Server but was not properly set up for 24/7 unattended broadcasting. Fonds-des-Nègres FM needed full RadioBOSS Cloud configuration from scratch.

No Listener Engagement for Nostalgie FM

Nostalgie FM's diaspora audience had no way to interact with the station — no song request system, no way for listeners to personalise their experience or feel connected to the programming.

No Content Platform for Fonds-des-Nègres FM

Community journalism for Fonds-des-Nègres FM existed on-air only — no online archive, no news blog, no programme schedule visible to listeners outside the broadcast range.

Station 1
🇺🇸 Nostalgie FM — New Jersey, USA

WordPress Website + RadioBOSS Windows Server + Song Requests

A full nostalgic Haitian music radio platform built for the global diaspora — custom WordPress site, RadioBOSS configured on Windows Server, and a unique automatic song request system.

1

WordPress Website

Built nostalgiefm.com on WordPress — custom theme with retro Haitian identity, live radio player on homepage, photo gallery (Flickr), video gallery (YouTube), blog with cultural articles, contact form, and social media integration (Facebook, Twitter, Instagram, WhatsApp).

2

RadioBOSS on Windows Server

Deployed and fully configured RadioBOSS on the client's Windows Server — installation, encoder setup, streaming server connection, bitrate configuration, playlist import by genre (Konpa, Mini-Djaz, traditional Haitian), and automation rules for 24/7 unattended broadcasting.

3

Playlist Organization & Automation

Organized the music library within RadioBOSS — categorized by era and genre, set up rotation rules, jingle scheduling, hourly events, and configured automation logic for a professional seamless 24/7 listening experience without repetition.

4

Custom Song Request System

Built a unique automatic song request system on the website — listeners browse the available music library, select their favorites, and the song plays shortly. Fairness controls enforce a maximum of 2 requests per user every 30 minutes. A feature that makes Nostalgie FM truly interactive.

Station 2
🇭🇹 Fonds-des-Nègres FM — Grand Sud, Haiti

French WordPress Platform + RadioBOSS Cloud + Community Features

A full community radio digital platform built in French for a Haitian audience — RadioBOSS Cloud streaming, show schedules, news journalism, photo/video archives, and team profiles.

1

French WordPress Website

Built fondsdesnegresfm.com on WordPress 6.9 — fully in French for the Haitian community. Custom theme matching the station's identity, responsive mobile design, navigation (Accueil, Actualités, Média, Émissions, Personnalités, Contact), and homepage hero with the station's tagline.

2

RadioBOSS Cloud Setup

Configured RadioBOSS Cloud streaming (c18.radioboss.fm:8652) from scratch — streaming account setup, stream URL, bitrate configuration, and integration into the WordPress website with a prominent "EN DIRECT" live player accessible from every page.

3

Programme Schedule — Émissions

Built a fully structured Émissions (Shows) section — Sports Info (20h–21h), Soirée Détente (18h–20h), Pause Midi (12h–14h) — with individual show pages, host information, and show times clearly displayed for the community audience.

4

News, Galleries & Community Pages

Built a full Actualités news blog, photo gallery, YouTube video replays section, team profiles for presenters and journalists, Personnalités pages for notable community figures, and a newsletter subscription system for email updates.
