The Challenge

From Audio-Only to Professional TV Broadcast

Sunset Sol Radio was streaming great music but had no visual identity on YouTube, a fragile local-PC setup, broken metadata, and an unorganized automation system.

No Professional Broadcast Presence

The station was streaming audio only with no visual identity on YouTube, missing a massive potential audience who expect a TV-style experience on video platforms.

PC-Dependent Broadcasting

The live stream required a local computer running 24/7 — any PC shutdown, crash, or power cut would kill the stream. Unsustainable for round-the-clock broadcasting.

Broken Metadata Display

Now Playing song titles were not updating correctly across stream overlays, causing incorrect or blank metadata in the live broadcast — poor listener experience and unprofessional appearance.

Unorganized Automation Structure

RadioBOSS scheduler was poorly organized — playlists conflicting, jingles misfiring, no reliable 24/7 flow. Color coding absent, events hard to read, management inefficient.

The Solution

A Complete YouTube Radio TV System

We built a fully integrated live broadcasting pipeline — from RadioBOSS Cloud to YouTube — with 6 custom branded live elements and cloud deployment for 24/7 stability.

1

RadioBOSS Cloud Integration

Connected the RadioBOSS Cloud streaming server directly into OBS Studio as a continuous live audio feed, ensuring seamless audio-video synchronization for the YouTube broadcast.

2

OBS Studio Configuration

Full OBS setup optimized specifically for 24/7 YouTube Live — bitrate, keyframe interval, stream stability settings, and crash recovery configured for continuous unattended broadcasting.

3

6 Custom Branded Live Elements

Designed and built: a live Now Playing metadata overlay, scrolling station ticker, UK live clock, Margate real-time weather widget, branded lower-thirds, and animated station logo — all matching Sunset Sol's sunset-inspired visual identity.

4

Metadata Pipeline Fix

Diagnosed and resolved the complete Now Playing metadata chain — from RadioBOSS Cloud through to OBS browser sources and the YouTube stream. Song titles now update live and accurately across all elements.

5

Scheduler & Playlist Rebuild

Fully reorganized the RadioBOSS scheduler structure — cleaned playlist logic, fixed jingle events, applied color coding for weekdays, and grouped events for easy management and long-term operation.

6

VPS Deployment Preparation

Configured and fully documented a cloud VPS deployment workflow so the entire broadcasting system can run 24/7 from a cloud server — no local PC needed, no single point of failure.
